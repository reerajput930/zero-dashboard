# zero-dashboard
under progress!
A full-stack analytics dashboard built with the MERN stack, featuring real-time data visualization through interactive charts, secure JWT-based authentication, and a responsive UI powered by Tailwind CSS. Architected with a client-server separation, managing state globally via Context API and persisting data through MongoDB. Deployed live on Netlify.
